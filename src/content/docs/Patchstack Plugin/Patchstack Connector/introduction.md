The Patchstack connector is used to connect your Drupal site to the Patchstack App.
For WordPress, the Patchstack plugin should be installed instead.

Joomla is no longer supported (connector deprecated June 2026; removed from the vulnerability database and VDP search August 2026). See [Joomla support deprecated](/patchstack-plugin/patchstack-connector/joomla-support-deprecated/).
